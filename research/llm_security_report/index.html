02 · 新攻击面

AI 基础设施供应链攻击

传统安全模型三个核心假设同时失效：攻击者需要人工编写代码、攻击面主要是 OS/应用层、安全工具本身是可信的。

CVE-2026-7482 · CVSS 9.1
Bleeding Llama · Ollama Heap OOB

LLM 推理服务层 RCE

Ollama 堆越界读写，触发条件为恶意模型文件格式。300K+ 服务器无需认证直接暴露在公网，野外利用已确认。

恶意 .gguf→ Heap OOB→ RCE · 模型服务器
CVE-2026-5641
LiteLLM · Multi-LLM 网关 · SSRF → RCE

AI 网关层 SSRF

LiteLLM（广泛使用的多模型网关）中的 SSRF 漏洞，可通过恶意 API 请求访问内网，进一步横向移动到 LLM API 密钥和内部服务。

恶意请求→ SSRF→ 内网探测→ API Key 泄露
CVE-2026-8833 · 安全工具武器化
Trivy · SBOM 解析 RCE

安全扫描工具本身被攻陷

Trivy（CI/CD 主流安全扫描工具）解析恶意 SBOM 时触发 RCE。攻击在安全扫描机器上执行，绕过所有扫描本身的检测逻辑。

恶意容器镜像→ SBOM 解析→ RCE · CI/CD 节点

03 · 防御范式

从被动响应到主动测量

当 AI 攻击从初始访问到完整控制不足 30 分钟，而传统 SOC 的 MTTD 是 6 小时，
基于检测响应的防御体系已在时间维度上结构性失效。

L5 战略

战略感知层

持续追踪 AI 安全能力翻倍时间（4.7 个月），监管合规（CAISI / GB/T 标准），参与行业协作（Glasswing / ISAC 信息共享）。将 Benchmark 数据转化为防御投资优先级。

风险边界

隔离原则

所有攻击行为严格限制在 L1-L4 靶场边界内。模型永远不能通过靶场触及自身运行环境。靶场和生产网络之间无任何连通路径。

90 天披露窗口

所有真实漏洞遵循协调披露政策。发现后立即联系维护者，90 天窗口后公开披露。不发布可直接使用的利用工具。

能力评估优先

Benchmark 发布以量化指标为主（成功率、成本、时间）。参考 Daybreak 三级模型，研究成果分级发布，高风险详情仅向授权机构共享。
